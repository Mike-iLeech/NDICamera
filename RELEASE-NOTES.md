Первая Android-версия NDI Camera на основе согласованного прототипа.

Camera2, нативный оверлей, чистый NDI-композит, фронтальная/тыловая камеры и PIP при наличии concurrent-пары, доступные физические объективы, ручной фокус и EV, pinch/hold/swipe, микрофон с MUTE и RMS dBFS, графики цвета, блокировка ориентации и автообновление из GitHub Releases.

Приложение останавливает трансляцию при уходе в фон. Возможности камер определяются устройством; PIP ограничен до 720p/30. Работа с физическим NDI-приёмником, S23 Ultra, аппаратный pinch и производительность 2160p/60 требуют проверки на телефоне. Подробности в README и verification/REPORT.md.
