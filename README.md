# NDI Camera

Нативное Android-приложение для передачи камеры телефона по NDI. Дизайн основан на утверждённом [интерактивном прототипе](prototype/index.html) и NDI ScreenCast.

## Возможности

- Тыловая и фронтальная камеры; PIP с заменой основной камеры, если Camera2 предоставляет совместимую concurrent-пару.
- Автоматический выбор сенсора через Camera2; зум камеры, вертикальный ползунок и pinch.
- Тап для AF/AE, удержание для фиксации, удержание со свайпом для EV; независимые AE-L/AF-L и ручной фокус, если поддерживаются камерой.
- Сетка, фонарь, белая экранная подсветка фронтальной камеры, RGB-гистограмма и вектроскоп.
- Доступные камерой разрешения 480–2160p и 25/30/50/60 FPS. PIP в первой версии ограничен 720p/30 и второй камерой до 640×480.
- Микрофон 48 кГц; mono дублируется в stereo NDI; RMS dBFS и MUTE с передачей цифрового нуля.
- Блокировка ориентации. Красная START/STOP. HUD можно скрыть.
- Имя NDI-источника, показ примерного сетевого битрейта, обновления из GitHub Releases раз в 24 часа. SHA-256, package, versionCode и подпись APK проверяются до установки.

В NDI отправляется отдельный OpenGL-композит камер. Оверлей, графики и экранная подсветка не захватываются. Приложение передаёт видео, пока открыто; при уходе в фон/блокировке экрана передача и камеры останавливаются. Установка обновления подтверждается Android.

## Сборка (Windows, PowerShell)

```powershell
./setup.ps1
./build.ps1 -DebugSigning
# Если SDK уже установлены, можно использовать их без повторной загрузки:
./build.ps1 -ToolRoot ../NDIScreenCast/tools -DebugSigning
```

Android SDK 35, NDK 28.2.13676358, JDK 21 и NDI SDK for Android устанавливаются в игнорируемый `tools/`. SDK NDI и Android имеют собственные лицензии. Приложение включает лицензионные уведомления NDI. Бинарные SDK и ключи не публикуются в исходниках.

Для релиза задайте `NDICAMERA_SIGNING_PASSWORD` в окружении или игнорируемом `signing/local.ps1` и выполните сборку без `-DebugSigning`. Сохраните `signing/release.jks` и пароль: будущие обновления требуют того же сертификата. Debug/CI APK имеют другой сертификат и не обновляют release-установку.

`release.ps1 -Tag v0.1.3 -Target <проверенный-SHA>` готовит `update.json`. Флаг `-Publish` публикует APK и манифест в GitHub Releases. Версия и versionCode следующего релиза должны увеличиваться.

Приложение использует автоматическую камеру: подходящий сенсор для текущего зума выбирает Android. В landscape быстрые инструменты центрированы в безопасной области на высоте 50 физических px; при пересечении с вырезом панель опускается под него.

## Ограничения и проверки

Список объективов и concurrent-пар зависит от прошивки. Samsung и другие производители могут не предоставлять все объективы сторонним приложениям; физическая проверка на S23 Ultra необходима. Выбор 2160p/60 не является обещанием измеренных 60 FPS: чтение RGBA из OpenGL и NDI Full Bandwidth требуют быстрых CPU/GPU и сети. При перегрузке очередь ограничена одним кадром, кадры пропускаются, UI не ожидает NDI.

Для приёмника нужна та же локальная сеть с доступным NDI discovery/mDNS и достаточной пропускной способностью. Показатель битрейта — приблизительный общий исходящий трафик UID, а не метрика кодека.

API: [Camera2 multi-camera](https://developer.android.com/media/camera/camera2/multi-camera), [concurrent cameras](https://source.android.com/docs/core/camera/concurrent-streaming).
